Detailed Description

template<typename View, typename Value>
struct ippl::detail::ParticleAttribAssignFunctor< View, Value >

Assign a value without NVCC's translation-unit-local lambda copy helpers.

Named functors remain safe when the host linker coalesces parallel_for instantiations emitted by different translation units.
